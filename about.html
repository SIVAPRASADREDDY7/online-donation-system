The Visionary Behind The Platform

Siva Prasad Reddy

The Online Donation Management System was conceptualized and developed by Siva Prasad Reddy with a clear objective: to revolutionize how charity contributions are collected, tracked, and verified.

Traditional donations often lack transparency regarding how funds are utilized. By integrating a full-stack architecture with a centralized MySQL Workbench relational database, every rupee donated is immutably logged with an authentic transaction ID, donor link, and campaign identifier.

🌟 Core Principles

1. 100% Relational Integrity

Using MySQL Foreign Keys between users, campaigns, and donations to guarantee clean, uncorrupted financial records.

2. Zero Hidden Overhead

Direct contribution from donor to cause with instant digital verification receipts generated immediately.

3. Community-Driven Empowerment

Enabling fundraisers to initiate verified campaigns for medical relief, orphan education, and food security.

System Architecture

MySQL Workbench Database Design

The backend is powered by Node.js, Express, and a MySQL relational database named online_donation.

Table 1: users

Stores donor & administrator credentials and roles.

  • 🔑 user_id (INT AUTO_INCREMENT PK)
  • 📝 name (VARCHAR(100))
  • 📧 email (VARCHAR(100) UNIQUE)
  • 🔒 password (VARCHAR(255))
  • 📱 phone (VARCHAR(15))
  • 🏷️ role (VARCHAR(30))

Table 2: campaigns

Stores verified social initiatives and fundraising goals.

  • 🔑 campaign_id (INT AUTO_INCREMENT PK)
  • 📝 title (VARCHAR(45))
  • 🎯 target_amount (VARCHAR(45))
  • 📅 start_date (VARCHAR(45))
  • ⏳ end_date (VARCHAR(45))
  • 📊 status (VARCHAR(45))

Table 3: donations

Logs every financial contribution with relational links.

  • 🔑 donation_id (INT AUTO_INCREMENT PK)
  • 🔗 user_id (FK -> users)
  • 🔗 campaign_id (FK -> campaigns)
  • 💰 amount (DECIMAL(10,2))
  • 🕒 donation_date (DATETIME)
  • ✅ payment_status (VARCHAR(30))
  • 🧾 transaction_id (VARCHAR(100) UNIQUE)
